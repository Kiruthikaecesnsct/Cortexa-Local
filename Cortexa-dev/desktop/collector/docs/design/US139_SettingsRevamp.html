What this shows

  • Settings is one page with a section list (ListBox, one tab stop, Up/Down/Home/End) and a content pane that uses the rest of the body width. The selected section is kept in the navigator singleton for the app session; Ctrl+, opens Settings on it.
  • AI model: three ProviderCard radio buttons + Model combo filtered by provider. Changes save at once (no Save button). The missing-key warning is the existing BannerView, Warning severity, with "Go to AI provider keys".
  • Extract: the Provider and model card is gone. The read-only model line sits directly above the action row. If the key is missing, Extract knowledge is disabled and its tooltip/HelpText uses the existing KeyMissingTitle copy.
  • Text is Cambria. Icons keep Segoe Fluent Icons. URLs, paths and model IDs keep Cascadia Mono at their old sizes. Cambria has no SemiBold face, so every SemiBold setter draws Bold (shown here as 700).
  • A failed save reverts the cards and the drop-down to the last saved choice and shows the error banner. Extract always reads the saved value.
  • At 880 px with the compact rail, About rows stack: label, value, then action.
  • Overline text (SOURCE, PROVIDER, AI MODEL) is stored uppercase. WPF has no text-transform or letter-spacing.
  • Provider tiles use a letter (C, G, B) instead of a brand logo or a guessed glyph. No logo assets ship, and the tile reads the same in high contrast.
