# US126: Extract Knowledge and Upload

## Prerequisites / scope

- **History polling moved to US127+US128**: This story focuses on extraction and upload only. History screen batch-status polling is now a separate concern in US127 (server GET endpoints) and US128 (History UI).
- **Item caching for retry is US133**: Batch request deduplication and caching is split into a follow-up story.
- **Collector server on localhost:5091**: The desktop collector backend runs independently; it is not started by run-local.ps1. Must be launched manually for E2E testing.
- **Knowledge prompt requirements**: Alpha requires the prompt to extract ideation/concepts/key points, not literal identifiers (e.g., class names, variable names). Extraction must be generalizable across domains.
