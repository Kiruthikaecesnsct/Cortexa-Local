# US159: Add Vertex AI to collector settings

## Prerequisites / scope

- **Pre-flight found a backend gap, folded in at Alpha's explicit call**: US158 wired `VertexDirectProvider` and the Vertex `HttpClient` base address to read project id/location from static `IOptions<VertexProviderOptions>` config, fixed at DI startup. User-entered values from the new Settings row have no path to the provider without this. Alpha chose to fold the fix into US159 (Task: "Persist user-entered Vertex project id and location, and read them in the provider") rather than split it into a prerequisite story, despite the pre-flight verdict recommending a split (it crosses from frontend into Application/Infrastructure and introduces a new contract).
- **Resulting scope**: US159 now also persists user-entered Vertex project id/location and makes `VertexDirectProvider` + the Vertex `HttpClient` read the persisted values per-call instead of only the static config bound at startup.
